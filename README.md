Sistema PHP

Este é um projeto em PHP puro, com as piores práticas possíveis, cujo objetivo é ser refatorado posteriomente utilizando as melhores práticas.

Requisitos:
* PHP 8.2.12
* HTML 5;
* CSS 3;
* Javascript 6;
* Servidor HTTP;
* Banco de dados MySQL/MariaDB 10.4
* Conexão PDO.

Funcionalidades:
* Login;
* Recuperação de senha;
* Usuários;
* Empresas;
* Produtos;
* Clientes;
* Estoques;
* Caixas;
* Bancos;
* Pedidos de Venda;
* Contas a Receber;
* Tesouraria;
